File Naming Convention

Rename your images before uploading so the AI knows exactly which URL goes where.

Question Figure

q1_fig.png q3_fig.png q7_fig.png

→ Goes into question_image column

Option Images (4 per question)

q2_A.png q2_B.png q2_C.png q2_D.png

→ Goes into options JSON as A/B/C/D URLs

Question with figure + image options

q5_fig.png q5_A.png q5_B.png q5_C.png q5_D.png

How AI uses this: After uploading, copy all URLs and paste them into ChatGPT/Claude along with your questions. The AI reads the filename in each URL (e.g. q3_fig, q3_A) and automatically places each URL in the correct CSV column and row.
